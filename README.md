## ✨ H5 核心功能

- **AI 打卡海报**：上传照片 → 实时叠加桂花粒子滤镜 + 品牌框线，一键保存分享（纯前端 Canvas 实现，每次生成桂花分布均不同）
- **优惠券链路**：9 元尝鲜券限领 1 张、7 天有效，分享解锁裂变券
- **数据看板**：PV、海报生成/保存、领券、门店查询等事件真实埋点采集，过程指标实时可追踪
- **智能体**：意图识别 → 知识库检索 → 合规护栏检查 → 模板化输出；功效类问题兜底、投诉自动转人工、知识库外不编造

## 🛠 技术说明

- H5：原生 HTML/CSS/JS 单页应用，零依赖，静态托管即可运行
- 智能体：自研规则引擎 + 结构化知识库，无外部 API 依赖
- AIGC 物料：文生图模型生成，全部记录提示词迭代过程（见 docs）
