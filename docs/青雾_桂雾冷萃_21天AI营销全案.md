## 一、营销策略
**核心观点**：以「秋日第一口桂香」为情绪锚点，通过「悬念种草→全渠道官宣→互动转化」三段式节奏，用AI工具放大内容产能与用户运营效率，实现声量与销量双达标。

### 1. 一句话核心主张
一杯桂雾冷萃，把江南秋天喝进嘴里。

### 2. 人群洞察
- **核心人群**：18-30岁，高校学生、入职3年内白领，集中在品牌门店所在的江浙区域（假设值，需客户确认）；
- **行为特征**：小红书日均使用时长45分钟以上，新品上市期优先看种草笔记决策，喜欢限定款、氛围感打卡，乐于分享高颜值饮品至社交平台；
- **情绪痛点**：秋季情绪敏感，向往松弛感与仪式感，对“秋日限定、季节专属”类产品抵抗力弱；
- **消费特征**：对价格敏感，偏好9.9-15元尝鲜券，习惯小程序点单、到店自提。

### 3. 传播主题
- 主话题：`#秋日第一杯桂花冷萃`
- 副主题：桂雾入秋，慢饮江南

### 4. 渠道组合策略
| 阶段 | 周期 | 核心渠道 | AI发挥作用 |
|------|------|----------|------------|
| 预热期 | 第1-7天 | 小红书、抖音 | AIGC生成悬念海报，智能体预埋评论区互动，批量产出预热文案 |
| 上市期 | 第8-21天 | 小红书、抖音、私域、门店 | AIGC全渠道物料投放，H5承接转化，智能体承接全渠道咨询与UGC产出 |

## 二、AIGC物料体系
**核心观点**：建立「正向提示词+负向提示词+三轮迭代」的标准化出图流程，6张物料覆盖预热-官宣-种草全场景，将传统7天出图周期压缩至48小时。

### 通用说明
- 生成工具：文心一格专业版
- 统一风格：清冷江南秋日感，浅青+暖金主色调，高级商业摄影质感
- 审核机制：AI出初稿 → 设计岗画面审核 → 策略岗调性审核 → 终稿输出

### 物料1：新品官宣主视觉海报
- **尺寸规格**：竖版3:4（适配小红书封面/抖音封面）；横版16:9（适配门店立牌/小程序banner）
- **画面元素与构图**：透明玻璃杯装桂雾冷萃，茶汤漂浮金桂与冰块，置于江南木质窗边，窗外逆光桂影；产品居中偏下，画面上方1/3为干净留白区
- **文案预留区**：画面上方三分之一区域，无杂物、无复杂光影，可直接叠加品牌logo与产品名

**正向提示词（定稿版）**
```
新式茶饮秋季新品主视觉海报，竖版3:4，透明玻璃杯盛放浅青绿色冷萃茶饮，表面漂浮细碎金黄色桂花与少量通透冰块，杯壁凝结细密水雾，杯子置于江南风格老屋深色木质窗边桌上，窗外是柔和秋日逆光，隐约可见朦胧桂花枝影，整体配色浅青色+暖金色，清冷江南秋日氛围感，高级商业产品摄影风格，质感细腻通透，浅景深。画面上方三分之一保持干净留白，仅保留柔和逆光和朦胧背景，不放置产品、花瓣或复杂元素，无任何文字、logo、水印
```

**负向提示词**
```
文字，logo，水印，人物正脸，塑料杯，纸杯，浓艳色彩，高饱和，杂乱背景，多余杂物，模糊，噪点，过度暖黄，卡通风格，手绘风格，夸张构图
```

**三轮迭代优化维度**
1. V1初稿：搭骨架——确认主体、场景、色调、留白位置
2. V2优化：提质感——强化杯壁水雾、冰块通透度、桂花颗粒感、光影层次
3. V3定稿：调商用——校准留白比例、统一品牌色、去除多余元素，满足排版要求

### 物料2：小红书种草图（共3张）

- **通用负向提示词**：文字、logo、水印、塑料杯、浓艳色彩、杂乱桌面、人物正脸、卡通风格
- **三轮迭代优化维度**

  2. V2：优化光影质感与留白比例
  3. V3：校准情绪氛围，确保悬念感与高级感

## 三、H5《寻桂集》产品方案
**核心观点**：打造「打卡生成→领券→跳转下单」的最短转化路径，通过AI海报生成功能实现社交裂变，承接全渠道种草流量。

### 1. 页面流程图
```
首页（活动主视觉 + 立即参与按钮）
    ├─ 门店查询页（选择城市 → 查看门店列表/地址/上线状态）
    ├─ AI生成海报页（上传照片 → 选择滤镜 → 生成专属桂花海报 → 保存分享）
    ├─ 优惠券领取页（领取9元尝鲜券 → 跳转小程序下单）
    └─ 产品详情页（配料/热量/甜度说明）
```

### 2. 每页转化目标
| 页面 | 核心转化目标 | 辅助目标 |
|------|--------------|----------|
| 首页 | 点击「立即参与」按钮进入活动 | 浏览活动规则，分享活动 |
| AI海报页 | 生成并保存海报，分享至社交平台 | 停留时长≥30秒 |
| 优惠券页 | 领取优惠券，跳转小程序下单 | 查看使用规则 |
| 门店查询页 | 查询就近门店，引导到店 | 收藏门店地址 |

### 3. 埋点事件清单
- 页面访问：PV/UV、停留时长、跳出率
- 行为事件：点击生成海报、海报保存成功、分享成功、点击领券、领券成功、跳转小程序、查询门店
- 转化指标：海报生成率、领券率、小程序跳转率、到店核销率（假设值，需对接小程序数据）

### 4. 优惠券与跳转逻辑
1. 每个微信账号限领1张9元新品立减券，券后低至X元（假设值，需客户确认产品定价）；
2. 领取后自动存入卡包，点击「立即使用」直接跳转品牌小程序「桂雾冷萃」商品页；
3. 优惠券有效期：领取后7天内有效，仅限到店自提/小程序下单使用；
4. 生成专属海报并分享成功，可额外获得1张满20减3元通用券，激励社交裂变。

## 四、AI智能体「青雾寻桂顾问」
**核心观点**：覆盖全渠道用户咨询与UGC产出两大场景，用标准化知识库+多风格文案模板，替代70%重复性人工工作，24小时响应。

### 1. 知识库字段
- 产品基础：品名、原料、茶底、甜度选项、热量、价格、上市时间
- 门店信息：覆盖城市、门店地址、营业时间、新品上线状态
- 活动规则：优惠券面额、使用期限、使用范围、核销方式
- 品牌常识：品牌定位、其他经典产品、点单攻略

### 2. 意图分类
1. 产品咨询类：配料、甜度、热量、口感
2. 门店查询类：地址、营业时间、是否有售
3. 活动咨询类：优惠券、活动时间、使用规则
4. 文案生成类：帮写小红书种草文案
5. 推荐类：根据口味推荐饮品/搭配
6. 敏感/投诉类：质量问题、退款、功效类提问

### 3. 多轮对话示例
> **用户**：桂雾冷萃甜不甜？
> **智能体**：桂雾冷萃是鲜萃绿茶底搭配金桂蜜调味，默认是微糖哦，茶味比较清爽，桂花香气很足～怕甜的话可以选无糖，也会有淡淡的桂花香。

> **用户**：帮我写个小红书文案，打卡风的
> **智能体**：
> 🍂秋日第一杯桂花冷萃终于喝到了！
> 浅绿茶汤飘着金桂，一口下去清爽不甜腻
> 江南秋天的味道被锁在杯子里了✨
> #桂雾冷萃 #秋日饮品 #新式茶饮 #桂花限定

### 4. 转人工标准
- 用户明确要求人工客服；
- 出现投诉、质量问题、退款等复杂诉求；
- 连续2轮无法匹配用户问题；
- 用户询问健康功效、医疗相关敏感问题。

### 5. 三种种草文案模板
1. **简短打卡版**：短句+emoji+话题标签，适合日常随手发
2. **走心氛围感版**：侧重秋日情绪、场景描写，适合深度种草
3. **测评向版**：从口味、甜度、性价比、颜值多维度客观评价

### 6. 合规护栏话术
- 功效类提问兜底：「饮品主要是风味体验哦，不具备保健功效，大家根据自己的口味喜好选择就好～」
- 质量/投诉兜底：「非常抱歉给你带来不好的体验，这边帮你转接人工客服详细处理哦」

## 六、KPI体系
**核心观点**：构建「北极星指标-过程指标-护栏指标」三层体系，所有指标可量化、可追踪，直接对应业务结果。

### 1. 北极星指标（最终结果）
- **指标**：新品首月销量占比
- **计算公式**：`新品销量 / 门店全品类总销量 × 100%`
- **目标值**：≥22%

### 2. 过程指标（路径追踪）
| 指标 | 计算公式 | 目标值 |
|------|----------|--------|
| 总曝光量 | 小红书曝光量 + 抖音曝光量 | ≥800万 |
| H5访问量 | H5独立访客数（UV） | ≥12万 |
| 优惠券领取量 | 成功领取优惠券的用户数 | ≥2.5万张 |
| 智能体对话量 | 智能体有效对话轮次 | ≥5万次 |
| AI辅助UGC产出 | 用户使用智能体生成文案数 | ≥100篇 |

### 3. 护栏指标（风险底线）
- 负面舆情量：平台负面提及数 ≤ 总提及量的0.5%
- 合规风险事件：AIGC侵权、文案违规、活动投诉 = 0起
- 智能体转人工率：转人工对话数 / 总对话数 ≤ 15%

## 七、预算分配与调优机制
**核心观点**：50万预算向流量与转化倾斜，建立中期调优机制，数据不达标时快速调整策略，确保KPI达成。

### 1. 预算分配（总预算50万元）
| 科目 | 金额 | 占比 | 对应支撑KPI |
|------|------|------|--------------|
| 信息流广告投放 | 32万 | 64% | 总曝光、H5访问、领券量 |
| 达人种草合作 | 12万 | 24% | 总曝光、话题声量、UGC |
| 优惠券补贴 | 6万 | 12% | 领券量、核销率、销量 |

> 注：AI工具成本、人力成本不计入本次投放预算。

### 2. 预算与KPI的支撑逻辑
- 32万信息流：按千次曝光40元测算，可覆盖800万曝光，落地页点击率1.5%即可带来12万H5访问；
- 12万达人：合作20位腰部达人+50位素人，覆盖小红书+抖音，撬动自然流量与话题讨论；
- 6万优惠券：按9元/张测算，可投放约6600张，叠加自然领取，目标2.5万张具备可行性（假设值，需根据定价复核）。

### 3. 上市期第7天不达标调优方案
若中期复盘时曝光量、领券量缺口≥20%，启动以下3项调优：
1. **信息流定向收紧**：暂停低转化人群包，预算向高点击的18-25岁女性、奶茶兴趣人群倾斜，提升落地页转化率；
2. **达人补量**：追加3-5位本地生活垂类达人，集中发布探店/测评笔记，撬动本地到店流量；
3. **智能体加玩法**：上线「邀请好友助力得第二杯半价」活动，通过智能体引导用户分享，提升裂变拉新。

## 八、合规风控
**核心观点**：建立全流程双层审核机制，从物料、文案、智能体、活动四个维度守住合规底线，零风险交付。

### 1. AIGC人工审核SOP
1. 初筛：AI生成后，运营岗检查是否有违禁元素、文字、水印、肖像风险；
2. 复核：设计岗审核画面版权、品牌调性、VI规范；
3. 终审：策略岗审核是否符合广告法、平台规则、客户要求；
4. 归档：终版物料标注版本号，留存生成记录与审核记录。

### 2. 文案禁用词列表
- 绝对化词：最、第一、顶级、极致、永久；
- 功效/医疗词：养生、减脂、清火、养颜、保健、治病、减肥；
- 虚假承诺词：百分百有效、永不腻、喝了就瘦；
- 违规极限词：国家级、最高级、第一品牌。

### 3. 智能体敏感问题兜底话术
- 健康功效类：「这款饮品主要是风味和口感体验哦，不具备保健功效，大家根据自己的口味喜好选择就好～」
- 食品安全类：「我们的产品都是严格按照食品安全标准制作的，原料都经过质检，可以放心饮用哦～如果有具体疑问可以帮你转接人工。」
